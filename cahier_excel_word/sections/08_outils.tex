\chapter{Outils proposés pour la réalisation}

Pour la conception et le développement de l'application, les outils suivants pourront être utilisés :

\begin{itemize}
    \item \textbf{React.js} pour développer l'interface web et l'éditeur.
    \item \textbf{Python et FastAPI} pour développer le backend.
    \item \textbf{MySQL} pour stocker les informations relatives aux utilisateurs et aux fichiers.
    \item \textbf{Docker} pour faciliter le déploiement de l'application.
    \item \textbf{Git} pour gérer et sauvegarder le code source.
\end{itemize}

L'application sera développée sous forme d'une plateforme web accessible depuis un navigateur.
