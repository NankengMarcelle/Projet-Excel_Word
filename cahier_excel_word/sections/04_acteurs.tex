\chapter{Acteurs}

\section{Utilisateur}

Les employés de l'organisation constituent les principaux utilisateurs de la plateforme. Ils pourront :

\begin{itemize}
    \item Se connecter à leurs comptes.
    \item Accéder à leurs espaces personnels.
    \item Consulter leurs fichiers.
    \item Importer de nouveaux fichiers.
    \item Ouvrir et modifier leurs fichiers.
    \item Enregistrer les modifications.
    \item Télécharger les fichiers Excel.
    \item Sélectionner une feuille pour la convertir en Word.
    \item Télécharger les documents Word générés.
\end{itemize}

\section{Administrateur}

L'administrateur assure la gestion générale de la plateforme. Il pourra notamment :

\begin{itemize}
    \item Gérer les comptes utilisateurs.
    \item Superviser le fonctionnement de la plateforme.
\end{itemize}
