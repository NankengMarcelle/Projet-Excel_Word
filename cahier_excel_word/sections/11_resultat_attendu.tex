\chapter{Résultat attendu}

À la fin du projet, les éléments suivants seront fournis :

\begin{itemize}
    \item Une application web fonctionnelle, permettant la gestion, l'édition et la conversion des fichiers Excel vers Word.
    \item Un manuel utilisateur, présentant les principales fonctionnalités et le mode d'utilisation de l'application.
    \item Une documentation technique, comprenant le cahier des charges, les différents diagrammes de conception et le cahier de déploiement.
\end{itemize}
