\chapter{Besoins non fonctionnels}

L'application devra respecter certains critères de qualité. Elle devra être :

\begin{itemize}
    \item \textbf{Simple à utiliser}, afin de permettre une prise en main rapide.
    \item \textbf{Accessible}, depuis un navigateur web.
    \item \textbf{Sécurisée}, avec un accès réservé aux utilisateurs autorisés.
    \item \textbf{Fiable}, afin d'éviter les pertes ou corruptions de fichiers.
    \item \textbf{Compatible}, avec les principaux formats de fichiers Excel retenus pour le projet.
\end{itemize}

La conversion vers Word devra respecter un niveau élevé de fidélité visuelle et structurelle. Le document généré devra notamment limiter :

\begin{itemize}
    \item Les changements de structure.
    \item Les pertes de mise en forme.
    \item Les débordements des colonnes.
    \item Les modifications non souhaitées des formats de données.
\end{itemize}
